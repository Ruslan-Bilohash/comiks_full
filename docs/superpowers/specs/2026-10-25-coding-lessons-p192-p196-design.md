# p192–p196: продовження курсу програмування

Дата: 2026-10-25

## Намір

Додати п’ять навчальних коміксів після `p191` для дітей і початківців, які вивчають норвезьку та основи програмування. Уроки мають виглядати й працювати так само, як `p183–p191`: шість панелей, норвезькі репліки з українським та англійським перекладом, словник і тест.

## Уроки

1. `p192` — **CSS gjør siden fin**: колір, фон, шрифт, клас.
2. `p193` — **Når vi klikker**: подія, кнопка, клік, реакція сторінки.
3. `p194` — **Variabler på nettsiden**: ім’я, значення, зміна лічильника.
4. `p195` — **Trygg på nettet**: пароль, приватні дані, підозріле посилання, доросла допомога.
5. `p196` — **Pus-siden er ferdig**: підсумковий мініпроєкт HTML + CSS + проста подія.

Рівень: A2. Категорія: `koding`. Постійні персонажі: Нора, Лео, Робо та Пус.

## Результат

- П’ять нових файлів `data/comic-192-*.js` … `data/comic-196-*.js`.
- Реєстрація файлів у чинному індексі та збірці.
- Для кожного уроку: 6 панелей, 3 питання `concept`, 1 завдання `algo`, 14–18 словникових одиниць.
- Один новий візуальний блок у тесті кожного уроку з чотирма окремими варіантами PNG.
- Разом 20 нових PNG у `img/tests/koding/p192/` … `p196/`.
- Окремий маніфест зображень і відновлювана черга генерації.

## Зображення тестів

Формат кожного файла: PNG 512×512, RGBA, справжнє прозоре тло, без тексту, рамки та водяних знаків. Стиль відповідає карткам Komiks·Lab: преміальний кольоровий 3D-мультфільм, м’які форми, студійне світло, один зрозумілий сюжет, 10% безпечних полів.

Зображення показують результат або поняття, а код і формулювання питання залишаються звичайним HTML-текстом інтерфейсу. Так генератору не потрібно правильно малювати HTML/CSS-код у картинці.

## Інтеграція без зміни дизайну

У `assets/koding.js` додається підтримка завдання `visual`, яке використовує вже наявні компоненти `q-prompt`, `opts pics`, `opt pic` та `panel-frame`. Нових CSS-правил і нової сторінки не буде. Дані питання міститимуть `promptImage`, `options[].image` та правильний ідентифікатор.

## Підходи

1. **Лише наявні SVG-генератори.** Найменше коду, але не виконує вимогу про згенеровані зображення.
2. **Нові PNG у чинному тестовому інтерфейсі — обрано.** Дає потрібні ілюстрації та не змінює дизайн; потрібна невелика підтримка типу `visual`.
3. **Окрема сторінка тестів.** Дає більше свободи, але дублює механіку і змінює навігацію та дизайн.

## Безпека й сумісність

- Не змінювати результати користувачів, ключі прогресу, авторизацію або MySQL.
- Нові ID тільки `p192–p196`; старі уроки та питання не змінювати.
- Якщо PNG ще не створений, візуальне питання не потрапляє до тесту.
- Не деплоїти без окремого підтвердження.

## Перевірка

- Синтаксис усіх нових JS-файлів.
- Унікальність ID та коректність реєстрації в індексі.
- Валідація 20 PNG: формат, 512×512, RGBA, прозорість, поля.
- Тест генератора питань для `p192–p196`.
- Перевірка читання коміксу, переходу до тесту, відповіді, наступного питання й результату.
- Мобільна перевірка без горизонтального переповнення.
