# SEO-перевірка — 21.10.2026

## Перевірені факти

- https://bilohash.com/comiks/ повертає HTTP 200, англійський title, canonical на себе; у HTML є hreflang.
- /comiks/lt/ повертає HTTP 200 і литовський title «Norvegiški komiksai besimokantiems (A1–B2) — Mokykis norvegų kalbos | Komiks·Lab». Canonical вказує на /comiks/lt/komiks/.
- /comiks/no/ та /comiks/uk/ повертають 200 і локалізовані title, canonical на відповідний /komiks/.
- /comiks/sitemap.xml доступний, містить мовні альтернативи; розмір близько 1,58 млн символів сам по собі не є проблемою.
- Локальний syncChrome змінює title і description під мову інтерфейсу. Це не тотожне окремій індексованій мовній сторінці. Перемикання DOM не змінює початковий HTML, який видно через «Перегляд коду сторінки».
- На основній сторінці англійський SEO-текст використовує «real voices», хоча сайт повідомляє про AI-озвучення.

## Пріоритетні рекомендації, без змін на сервері

1. Узгодити назву Learning Norwegian / Komiks·Lab у сайті, Google Play, title, OG і структурованих даних. Не перейменовувати автоматично без рішення власника.
2. Забезпечити прямі HTML-посилання на мовні URL, а не лише збереження вибору в localStorage. Для кожної мови перевірити локалізовані title, description, OG, текст сторінки й взаємні hreflang. Литовська версія вже існує — створювати дубль не потрібно.
3. Перевірити цілі canonical /lt/komiks/, /no/komiks/, /uk/komiks/: чи це навмисно еквівалентні сторінки, чи головна й каталог мають різний зміст. Наявність такого canonical сама по собі не доводить помилку.
4. Замінити неоднозначне «real voices» на правдиве пояснення якісного синтезованого норвезького озвучення.
5. У Search Console перевірити індексацію мовних сторінок, обрану Google canonical, пошукові запити та Core Web Vitals. Доступу до цих приватних показників у цій перевірці не було; оцінку швидкодії не вигадуємо.
6. Новий випадковий hero — покращення знайомства з каталогом, не гарантія росту позицій. Зберігати постійний H1 та доступні посилання на всі історії незалежно від випадкового кадру.

Джерело: https://developers.google.com/search/docs/specialty/international/managing-multi-regional-sites

## Реалізований локальний hero

Вибір із каталогу публічних коміксів: три завантаження один комікс, четверте — інший. Вибір зберігається на пристрої; повторний рендер без перезавантаження не рахується. Play озвучує перший кадр через наявний Speech; окреме посилання відкриває історію. SVG зберігає репліки та переклади, кнопка розміщена під кадром і не перекриває його.

Перевірено: 6 модульних тестів; валідатор 89 коміксів; Chromium mobile smoke — ротація, відсутність горизонтального переповнення, 6 розділів, MP3, без runtime errors. Нативний Android цим тестом не перевірявся. Зміни не опубліковано, dist не перебудовано.
