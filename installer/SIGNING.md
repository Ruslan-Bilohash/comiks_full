# Підпис інсталятора та вікно SmartScreen

## Коротко

Синє вікно «ОС Windows захистила цей ПК» — це **не антивірус і не про віруси**.
Це фільтр SmartScreen, і він спрацьовує на кожній програмі, яку завантажило ще
мало людей. Формально це називається «немає репутації».

Прибрати його можна трьома способами, і лише два з них справжні:

| Спосіб | Ціна | Коли зникне попередження |
|---|---|---|
| **Нічого не робити** | 0 | саме, коли назбирається кілька сотень завантажень |
| **EV Code Signing** | ~350–600 $/рік | **одразу**, з першого ж файлу |
| **OV (звичайний) Code Signing** | ~100–250 $/рік | через кілька тижнів і сотень завантажень |
| ~~Самопідписаний сертифікат~~ | 0 | **ніколи** — див. нижче |

> **Самопідписаний сертифікат не допомагає.** Windows не довіряє сертифікату,
> який ви виписали собі самі: попередження лишиться, а в деталях з'явиться
> «невідомий видавець» із вашим іменем. Це гірше, ніж без підпису, бо виглядає
> як спроба здаватися тим, ким ви не є. Тому в цьому проєкті його немає.

---

## Що вже зроблено безкоштовно

* **Повні метадані версії** у `.exe`: видавець, продукт, версія, авторські права.
  Самі по собі попередження не прибирають, але файл без них фільтри оцінюють гірше.
* **Без прав адміністратора**: інсталятор ставить усе в теку користувача й не
  викликає UAC — на один тривожний екран менше.
* **Пояснення на сторінці** `#/install`: що це за вікно і які саме два слова
  натиснути. Людина, яка розуміє, що бачить, доходить до кінця встановлення.
* **Шлях зовсім без попереджень**: кнопка «Встановити застосунок» у браузері.
  Ярлик той самий, вікно те саме — але ставить його сам Edge чи Chrome, тому
  SmartScreen не бере участі. Для більшості це найкращий варіант.

## Коли купите сертифікат

### 1. Що саме купувати

Для **EV** (миттєва репутація) потрібні:
* зареєстрована юридична особа або ФОП — на фізичну особу EV не видають;
* перевірка документів у центру сертифікації (кілька днів);
* апаратний токен або хмарний HSM — ключ не можна просто зберегти файлом.

Для **OV** достатньо підтвердити особу, але репутацію доведеться напрацьовувати.

Продавці: Sectigo, DigiCert, GlobalSign, SSL.com. Дешевше — через реселерів
(Codegic, SignMyCode) — той самий сертифікат, нижча ціна.

### 2. Налаштувати Inno Setup

Один раз, у графічному Inno Setup: **Tools → Configure Sign Tools… → Add**

Ім'я: `komiks`

Команда (для файлу `.pfx`):

```
"C:\Program Files (x86)\Windows Kits\10\bin\10.0.22621.0\x64\signtool.exe" sign /f "C:\шлях\до\cert.pfx" /p ПАРОЛЬ /fd sha256 /tr http://timestamp.sectigo.com /td sha256 $f
```

Для апаратного токена (EV) замість `/f` і `/p` використовується `/n "Ім'я видавця"`
або `/sha1 <відбиток>` — залежно від того, як токен ставить сертифікат у сховище.

> **Мітка часу (`/tr`) обов'язкова.** Без неї підпис перестане діяти того дня,
> коли закінчиться сертифікат, і всі раніше завантажені інсталятори почнуть
> лаятися.

### 3. Зібрати підписане

```bash
cd C:\comiks\installer && "%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" /DSIGN komikslab.iss
```

```bash
cd C:\comiks\installer && "%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" /DSIGN /DFULL komikslab.iss
```

Ключ `/DSIGN` вмикає в скрипті `SignTool=komiks` і `SignedUninstaller=yes` —
підписується і сам інсталятор, і програма видалення. Без другого попередження
вилізе вже під час деінсталяції.

### 4. Перевірити

```powershell
Get-AuthenticodeSignature "C:\comiks\installer\out\KomiksLab-Setup.exe" | Format-List Status, SignerCertificate
```

Має бути `Status: Valid` і ваше ім'я у `SignerCertificate`.

## Збірка без підпису (як зараз)

```bash
cd C:\comiks\installer && "%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" komikslab.iss
```

```bash
cd C:\comiks\installer && "%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe" /DFULL komikslab.iss
```

Готові файли — у `installer/out/`. Повна версія бере вміст із
`C:\komiks-android-offline\www` (той самий, що й офлайн-APK), тож перед нею
варто оновити його: `node tools/build-www.js` у тому сховищі.
