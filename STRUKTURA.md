# Комікс·Lab — структура проєкту

Живий сайт: **https://bilohash.com/comiks/**  
Локальна робоча копія: `C:\comiks\`  
Публікується лише вміст **`dist/`** (збірка `node tools/build.js` / `tools\update.bat`).

Цей файл — карта коду й опис файлів. **Код проєкту тут не змінювався.**  
Дата огляду: 2026-09-18.

---

## Що це

Односторінковий тренажер норвезької (bokmål) у браузері: комікси A1–B2 з нейроголосами, переклад при наведенні, тести, граматика, слова, математика, шахи й **онлайн-ігри в кімнатах з QR**.

Інтерфейс: `no` / `uk` / `en` (за замовчуванням норвезька).  
Навчальний текст і тести коміксів — норвезькою. Підказка при наведенні — українська + англійська (+ арабська, якщо увімкнено).

Без збірки Webpack: HTML + CSS + JS. Працює з `file://`, але **онлайн-кімнати потребують https://**.

---

## Як стартує сторінка

```
index.html
  → data/index.js     (реєстр + version)
  → assets/boot.js    (підключає shared + комікси + app.js з ?v=version)
  → assets/app.js     (маршрути #/..., малює UI)
```

`boot.js` ставить `async = false`, тож файли качаються паралельно, а виконуються по черзі. Service Worker (`sw.js`) реєструється лише на https (не localhost).

Кеш браузера ламається полем `KOMIKS_DATA.version` (його пише `build.js`).

## Онлайн-ігри (вже в коді)

Усі кімнати — **без ігрового сервера**: ведучий тримає стан, телефони з’єднуються через **PeerJS (публічний брокер 0.peerjs.com)** + QR.

1. **Гра разом** (`game.js`) — вікторина норвезькою на час, бали за швидкість, спільне читання коміксу перед питаннями. ID кімнати: `komiks-lab-room-<КОД>`.
2. **Math Rocket з класом** (`rocket.js`) — однакові приклади за `seed`, кінець раунду від годинника ведучого. ID: `komiks-lab-rocket-<КОД>`.
3. **Логік-гонка** (`race.js`) — **нова гра в журналі** («НОВА ГРА» / «NYTT SPILL»). Аватари біжать доріжками; правильна відповідь — крок уперед, помилка — спотикання. Траса на моніторі, задачі на телефонах; або гонка проти ботів. Нагорода — скриня з аксесуарами.
4. **Шахи** (`chess.js`) — бот / друг / турнір класу, нотація норвезькою.

Друзі (`friends.js`) можуть кликати в гонку або вікторину.

## Нова гра — що вже є і що варто обговорити

У `extras.js` Логік-гонка вже підписана як нова онлайн-гра для навчання. Ідея: не «хто запам’ятав сюжет коміксу», а **чесна логіка**, яку може грати весь клас одночасно.

Щоб думати далі (нічого не кодити, поки не вирішимо):

- Чи Логік-гонка — та гра, про яку мова, чи хочеться **іншу** (наприклад, норвезькі слова на трасі, диктант на час, «збери речення» командами)?
- Чи лишаємо PeerJS, чи потрібен власний маленький realtime-сервер (стабільніше за шкільним Wi-Fi)?
- Чи питання гонки мають озвучуватись норвезькою, як у вікторині?
- Чи боти мають бути явно позначені як ШІ (у допомозі вже є прозорість)?

## Знайдені проблеми й ризики (не правив)

Це спостереження з коду й живого сайту. Можна розбирати по одному.

### 1. `messages.js` не підключений
Файл і `api/messages.php` є, але `messages.js` **немає** в `data/index.js` → `shared` і **немає** в списку копіювання `tools/build.js`. Пошук по репозиторію не знаходить жодного `messages.js` крім самого файла. Сторінки `#/messages` / `#/privacy` з клієнтського боку, ймовірно, не відкриються.

### 2. README і CLAUDE.md роз’їхались з кодом
- README пише **21 історію** — у реєстрі **30** (`p90`–`p119`).
- CLAUDE описує стару шапку (ховати help/voice на 620/480), без race/chess/auth/messages.
- У шаблоні `_template.js` список персонажів коротший, ніж у живих коміксах (є Ruslan, Alina, Denys, Humphrey, Musa, Morten…).

### 3. Онлайн залежить від чужого брокера
Кімнати тримаються на публічному PeerJS. Якщо брокер лежить, фаєрвол школи ріже WebRTC, або два NAT «не дружать» — QR покаже кімнату, а телефони не зайдуть. Повідомлення `err_net` є, але вчитель не завжди зрозуміє причину.

### 4. Service Worker
`sw.js`: мережа → запис у кеш; якщо мережа впала — віддає кеш або **завжди `index.html`**. Офлайн-завантаження `app.js` може отримати HTML замість JS. Кеш оболонки оновлюється з версією в `build.js` (`komiks-<version>`), це добре.

### 5. Два світи акаунтів
Локальні користувачі (`localStorage`, у старих нотатках пароль за замовчуванням `12345`) і серверні (`api/auth.php`, пошта, 8+ символів). Гість на іншому телефоні не побачить прогрес, поки не зареєструється. Друзі/повідомлення/пошук гравців очікують сервер.

### 6. Норвезький UI і «одна мова перекладу»
`T()` у `app.js`: якщо інтерфейс `no`, картки/«Пари» беруть **англійську** як єдиний переклад (`ui === 'no' ? 'en' : ui`). Для норвезького учня це може бути несподіванкою (хочеться українську або навпаки).

### 7. Згода й мова
Вікно згоди малюється мовою `ui`. Новий відвідувач тепер стартує з `no`. Старий `localStorage comiks.ui=uk` лишає українську, поки не змінять селектор.

### 8. Шапка (те, що вже ловили)
Бургер до 1100 px: назва · мова · ☰. Раніше `grid-column` без `grid-row` міг скинути селектор мови **всередину меню над Logg inn**. У CSS уже є `grid-row: 1` — якщо на телефоні знову «мова над Logg inn», варто перевірити, чи на хостингу саме цей `style.css` (query `?v=` з `data/index.js`).

### 9. `file://`
Сайт відкриється, але: немає PeerJS-кімнат, немає PHP-акаунтів, мікрофон/TTS обмежені політикою браузера.

### 10. Приватні комікси
`_private/` не в реєстрі — добре. Не публікувати на хостинг.

### 11. Аудіо
Тисячі mp3. Якщо ключ не в `data/audio.js`, браузер іде на Speech Synthesis — на багатьох телефонах **тиша**. Є `audit-audio.js`.

### 12. Пробні скрипти в `tools/`
`_probe_header.py`, `_probe_no.py` — службові, не частина продукту.
