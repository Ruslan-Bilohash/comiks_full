# 🗂 Структура проєкту Комікс·Lab

Одна кодова база живить три речі: **сайт** `bilohash.com/comiks/`, **застосунок**
для Android та iOS і **офлайн-версію**. Нічого не дублюється — застосунок бере
ту саму збірку, що й сайт.

```
C:\comiks\
├── index.html              оболонка сайту: <head>, SEO-текст, заставка
├── sw.js                   офлайн-кеш (Service Worker)
├── manifest.webmanifest    щоб сайт ставився як застосунок із браузера
├── admin.php               панель адміністратора (не входить у застосунок)
│                           ↳ p=diag — 🩺 дебагер: перевіряє розгортання й безпеку
├── .htaccess               заголовки безпеки, кеш статики, закриті робочі теки
│
├── assets\                 увесь код інтерфейсу
├── data\                   вміст: комікси, слова, словники перекладу
├── api\                    сервер на PHP + MySQL
├── audio\                  10 429 записаних озвучень (mp3)
├── icons\                  іконки й екрани запуску всіх розмірів
├── photo\                  кадри фото-коміксів
├── tools\                  збірка та перевірки
├── app\                    мобільний застосунок (Capacitor)
├── store\                  матеріали для Google Play / App Store
└── dist\                   ГОТОВА ЗБІРКА — саме її заливають на сервер
```

---

## assets\ — код інтерфейсу

Звичайний JavaScript без складальників. `boot.js` читає список файлів із
`data/index.js` і підвантажує їх по черзі; `app.js` — останній.

| файл | за що відповідає |
|---|---|
| `boot.js` | завантажувач: читає список і тягне решту |
| `app.js` | ядро: маршрути, читалка, тести, картки, налаштування, кабінет |
| `art.js` | малює кадри коміксів у SVG (фони, персонажі, бульбашки) |
| `i18n.js` | інтерфейс: uk, en, no, ar |
| `i18n-eu.js` | інтерфейс: de, pl, tr, lt |
| `style.css` | увесь вигляд |

**Навчання:** `words.js` · `grammar.js` · `english.js` · `math.js` · `pairs.js` ·
`write.js` · `exam.js` · `placement.js` · `call.js`

**Ігри:** `race.js` (Логік-гонка) · `rocket.js` (Math Rocket) · `chess.js` ·
`game.js` (Гра разом) · `music.js` (фонова музика)

**Спільнота:** `auth.js` (вхід і синхронізація) · `friends.js` · `players.js` ·
`messages.js` · `alerts.js` · `profile.js` · `avatars.js`

**Малюнки:** `pics.js` … `pics7.js` — 314 намальованих іконок для тестів замість емодзі.

**Решта:** `extras.js` (рейтинг, довідка, карта сайту, журнал) · `news.js` ·
`feedback.js` · `teacher.js` · `install.js` · `premium.js` · `icons.js` ·
`a11y.js` · `bots.js` · `vendor\` (PeerJS і QR)

## data\ — вміст

| файл | що всередині |
|---|---|
| `index.js` | **головний список**: версія збірки + які файли вантажити |
| `comic-*.js` | 75 коміксів: кадри, репліки, словник, переклади uk/en |
| `words.js`, `words2.js`, `words3.js` | 972 слова за 47 темами |
| `grammar.js` | 16 тем граматики з таблицями |
| `characters.js` | хто є хто: зовнішність, голос, ім'я |
| `dictionary.js` | норвезько-український словник для підказок |
| `arabic.js` | арабські переклади за англійським рядком |
| `lang-de.js`, `lang-pl.js`, `lang-tr.js`, `lang-lt.js` | словники нових мов |
| `audio.js` | який текст у якому mp3-файлі |

**Як влаштовані переклади.** Українська, англійська й норвезька лежать
у самому коміксі. Решта мов — окремими словниками «англійський рядок → переклад»,
які вантажаться лише тоді, коли учень увімкнув цю мову.

## api\ — сервер

PHP + MySQL. Усі таблиці з префіксом `kl_`, схема оновлюється сама
(`SCHEMA_VERSION` у `lib.php`).

| файл | що робить |
|---|---|
| `lib.php` | спільне: база, сесії, CSRF, ліміти, пошта, **дозвіл для застосунку (CORS)** |
| `auth.php` | реєстрація, вхід, **синхронізація прогресу** |
| `players.php` | каталог гравців і рейтинг |
| `wall.php`, `messages.php`, `notify.php` | стіни, повідомлення, сповіщення |
| `call.php`, `realtime.php`, `tts.php` | дзвінок і озвучення через ШІ |
| `write.php` | перевірка письма через ШІ |
| `config.php` | **паролі й ключі — ніколи не потрапляє у збірку** |

Таблиці: `kl_users`, `kl_sessions`, `kl_user_data` (прогрес), `kl_players`,
`kl_walls`, `kl_comments`, `kl_messages`, `kl_events`, `kl_notices`, `kl_invites`,
`kl_bans`, `kl_feedback`, `kl_billing`, `kl_teachers`, `kl_rate`.

## tools\ — збірка й перевірки

| команда | що робить |
|---|---|
| `node tools/build.js` | **головна збірка**: версія, SEO, сторінки коміксів, `dist/` |
| `node tools/check.js` | чи має кожне норвезьке слово переклад uk/en |
| `node tools/audit-all.js` | **усі перевірки одним запуском** |
| `node tools/check-lang.js` | помилки в словниках і таблицях інтерфейсу |
| `node tools/audit-lang.js` | цілість коміксів і покриття мовами |
| `node tools/audit-audio.js` | чи кожен текст має запис |
| `node tools/build-audio-list.js` + `python tools/gen_audio.py` | записати нові озвучення |
| `node tools/build-langpack.js de pl tr lt` | зібрати словники з `tools/lang/*.tsv` |
| `python tools/gen-icons.py` | перемалювати всі іконки |
| `node tools/gen-store.js` | знімки екрана для магазину |
| `python tools/gen-feature.py` | банер 1024×500 для Google Play |

Тексти для перекладу лежать у `tools/lang/<код>/*.tsv` у вигляді
`англійський рядок ⇥ переклад`. Файли можна доповнювати частинами —
чого ще немає, показується англійською.

## app\ — мобільний застосунок

```
app\
├── capacitor.config.json   назва, іконка, дозволені адреси
├── package.json            команди
├── ANDROID.md              як зібрати й опублікувати
├── resources\              іконка 1024×1024 і екрани запуску
├── tools\prepare-web.js    збирає app/www із dist/
├── tools\serve.js          локальний перегляд застосунку
├── www\                    ← вміст застосунку (створюється)
└── android\                ← проєкт Android Studio (створюється)
```

Застосунок носить лише файли. Акаунти, рейтинг, друзі, дзвінок і перевірка
письма ходять на `bilohash.com` — і працюють із **тією самою MySQL**, що й сайт.
