1Перевірити, що все ціле

Одна команда перевіряє комікси, переклади, озвучення, відсутність паролів у збірці, розмір застосунку й матеріали для магазину.

cd C:\comiks
node tools\audit-all.js

Має закінчитися рядком ✅ Усе гаразд — можна публікувати. Якщо ні — виправте те, на що вкаже, і запустіть ще раз.

2Залити сайт

Онлайн-версія застосунку звертається до сервера: акаунти, рейтинг, друзі, дзвінок. Тому спершу оновіть сайт.

node tools\build.js

Залийте весь вміст теки dist\ у public_html/comiks/ на Hostinger.

⚠️ Найважливіше в цьому кроці Серед залитого обов'язково має бути новий api/lib.php. Саме він дозволяє застосунку звертатися до сервера. Без нього застосунок працюватиме лише як читалка: ні входу, ні рейтингу, ні синхронізації прогресу.

Перевірити, що сервер пускає застосунок:

curl -i -H "Origin: https://localhost" https://bilohash.com/comiks/api/players.php?sort=stars

У відповіді має бути рядок Access-Control-Allow-Origin: https://localhost.

3Подивитися застосунок на комп'ютері

Перед складанням варто побачити те саме, що покаже телефон. Є два варіанти застосунку:

ВаріантКомандаРозмірКому
Онлайн
з акаунтами		node app\tools\prepare-web.js --light
node app\tools\serve.js		15 МБосновний — прогрес синхронізується з сайтом
Офлайн
без акаунтів		node app\android_offline\build.js --serve148 МБпростіший для перевірки Google: не збирає даних

Відкрийте localhost:8970 (онлайн) або localhost:8971 (офлайн) і звузьте вікно до ширини телефона.

Що перевірити Комікс відкривається й звучить · тест проходиться й уміщається на екран · «Пари» працюють · (для онлайн-версії) вхід в акаунт тримається.

4Поставити інструменти складання

На вашому комп'ютері їх ще немає — перевірено, java не знайдено.

  1. JDK 17 — adoptium.net → Temurin 17, Windows x64, файл .msi
  2. Android Studio — developer.android.com/studio. Під час першого запуску він сам поставить Android SDK (кілька гігабайтів).
java -version

Має показати версію 17.

5Зібрати застосунок і підписати

cd C:\comiks\app
npm install
npm run add:android
npm run android

Відкриється Android Studio з готовим проєктом.

Ключ підпису — робиться один раз на все життя застосунку

Build → Generate Signed App Bundle → Android App Bundle → Create new…

⚠️ Збережіть файл .jks і паролі в надійному місці Це єдиний ключ вашого застосунку. Якщо його загубити, випустити оновлення буде неможливо — доведеться публікувати застосунок заново під іншою назвою, втративши всіх користувачів і відгуки. Зробіть копію в хмару й на флешку.

6Обліковий запис розробника

Learn Norwegian (Bokmål) the way people actually speak it — through short, funny comics.

COMPLETELY FREE

MADE FOR
People moving to Norway, international workers and families, and anyone preparing for a Norwegian course or the Norskprøven exam. Children can use it with a parent.

All stories, characters, drawings and voices are fictional and created with artificial intelligence.

9Тестування й випуск

  1. Testing → Internal testing — залийте .aab, додайте свою пошту, поставте застосунок за отриманим посиланням і перевірте на живому телефоні.
  2. Переконайтеся, що працюють: вхід в акаунт, рейтинг, звук, мікрофон, тест на весь екран.
  3. Production → Create new release → той самий .aab → Send for review.
⚠️ Не пропускайте внутрішнє тестування Це єдиний спосіб побачити застосунок на справжньому телефоні до того, як його побачать люди. Помилку в релізі виправляти довше, ніж перевірити зараз.

Перша перевірка триває від кількох годин до тижня. Оновлення проходять швидше.

🔄 Як випускати оновлення

node tools\build.js
node app\tools\prepare-web.js --light
cd app && npm run android

У файлі app\android\app\build.gradle підніміть:

  • versionCode — ціле число, обов'язково більше за попереднє (1 → 2 → 3…). Google відхилить бандл із тим самим номером.
  • versionName — те, що бачить людина: 1.1, 1.2…

Далі знову Generate Signed App Bundle — тим самим ключем.
