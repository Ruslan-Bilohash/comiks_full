# 📱 Комікс·Lab — мобільний застосунок (App Store + Google Play)

Один проєкт на **Capacitor**: той самий сайт працює як застосунок на iPhone і Android.
Нічого переписувати не треба — беремо готову збірку `dist/` і пакуємо її в застосунок.

```
app/
  package.json            налаштування й команди
  capacitor.config.json   назва, іконка, дозволені адреси
  tools/prepare-web.js    збирає app/www із dist/
  www/                    вміст застосунку (створюється автоматично)
  android/                проєкт Android Studio (створюється командою)
  ios/                    проєкт Xcode (створюється на Mac)
```

## Перший запуск (один раз)

```bash
cd app
npm install
npm run add:android          # створює app/android
npm run add:ios              # тільки на Mac, створює app/ios
```

## Щоденна робота

```bash
node tools/build.js          # зібрати сайт (у корені проєкту)
cd app && npm run android    # оновити www і відкрити Android Studio
cd app && npm run ios        # те саме для Xcode (Mac)
```

## Три режими вмісту

| Команда | Що всередині | Розмір | Кому |
|---|---|---|---|
| `node tools/prepare-web.js` | увесь сайт + усе аудіо | ~100 МБ | офлайн-версія |
| `node tools/prepare-web.js --light` | сайт + слова й перші комікси | ~15 МБ | **рекомендовано для сторів** |
| `node tools/prepare-web.js --remote` | лише оболонка, сайт вантажиться онлайн | < 1 МБ | швидкий тест |

У light- і full-режимі серверні речі (акаунти, дзвінки, стіни, повідомлення) автоматично
ходять на `https://bilohash.com/comiks/` — у застосунку немає PHP, тому сервер лишається один.

## Що треба для публікації

**Google Play**
1. Обліковий запис розробника (одноразово 25 $).
2. У Android Studio: *Build → Generate Signed Bundle* → `.aab`, ключ зберегти назавжди.
3. У Play Console: опис, 4–8 знімків екрана, іконка 512×512, банер 1024×500, політика приватності
   (можна вказати сторінку «Умови використання» на сайті).
4. Вікова категорія: 3+ (навчальний контент). Обов’язково вкажіть, що частина вмісту створена ШІ.

**App Store**
1. Apple Developer Program (99 $ на рік) і Mac із Xcode.
2. В Xcode: *Product → Archive* → *Distribute App*.
3. У App Store Connect: опис, знімки для 6,7″ і 5,5″, іконка 1024×1024, політика приватності.
4. У формі приватності зазначте: пошта й ім’я — для акаунта; мікрофон — лише для вимови
   й дзвінків, записи не зберігаються.

## Дозволи

- **Мікрофон** — вимова слів і телефонні дзвінки з ШІ. Тексти пояснень:
  - iOS `Info.plist` → `NSMicrophoneUsageDescription`:
    «Мікрофон потрібен, щоб перевіряти вимову й вести розмову норвезькою.»
  - Android `AndroidManifest.xml` → `<uses-permission android:name="android.permission.RECORD_AUDIO" />`
- **Інтернет** — акаунти, дзвінки, спільнота. Додається автоматично.
- Камера, геолокація, контакти **не потрібні** — не додавайте їх, це спрощує перевірку.

## Іконки та заставка

Усі вихідні файли вже згенеровані — їх малює `tools/gen-icons.py` у корені проєкту
(`python tools/gen-icons.py`, потрібен Pillow). У `app/resources/` лежать:

| Файл | Що це |
|---|---|
| `icon.png` (1024) | іконка застосунку |
| `icon-foreground.png` + `icon-background.png` | адаптивна іконка Android (кругла, квадратна, крапля) |
| `splash.png`, `splash-dark.png` (2732) | заставка запуску, світла й темна |

Далі Capacitor сам розкладе їх по всіх щільностях:

```bash
npx @capacitor/assets generate --iconBackgroundColor '#ffd23f' --splashBackgroundColor '#fff8ea'
```

Той самий набір іконок працює й у браузері — ярлик із робочого стола (Windows),
з головного екрана (Android) і з Safari на iPhone бере їх із `manifest.webmanifest`.

## Часті питання

**Чи не відхилять застосунок як «просто сайт»?**
З light-режимом ні: вміст лежить усередині, працює офлайн, є нативні дозволи (мікрофон,
вібрація, сплеш). Ми свідомо не робимо `--remote` для релізу.

**Як оновлювати?**
Дрібні зміни сайту → користувачі бачать їх одразу (сторінки вантажаться з `dist` усередині
застосунку лише в офлайні, решта — з сайту). Зміни всередині застосунку → нова збірка в сторі.
